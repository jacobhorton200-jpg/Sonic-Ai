How this works

This page uses EmulatorJS with the Genesis Plus GX core. On supported builds it asks the libretro core for the Genesis system-RAM pointer, then feeds Sonic's real RAM state into Cognition v3.

The AI does not teleport Sonic or write rings/lives/position. It sends controller inputs. A cognition-patched ROM can also use the mailbox bridge for richer native movement execution.

Compatibility note: stock Sonic 1 can run here. AI Play requires the emulator core to expose system RAM to JavaScript; if that hook is unavailable, the game still plays normally and the page will tell you the bridge is unavailable.
